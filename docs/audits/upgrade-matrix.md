## Findings (→ WA-032)
1. **D8Charge case-mismatch (confirmed bug):** `AnyOf[Thor, Immortal, Warhound]` but tags are `ThorAP` / `WarHound` → only **Immortal** can roll it. Fix the two ids.
2. **Battlecruiser + Yamato (confirmed):** BC can roll Yamato, which it already has natively. Add `NoneOf[Battlecruiser]`.
3. **Raven + SeekerMissile (verify):** unguarded; is it a duplicate of a native Raven ability in this mod?
4. **Battlecruiser + Hyperjump (inconsistency):** BC's card hard-adds a Hyperjump button but BC isn't in Hyperjump's AnyOf list — it uses it natively, can't roll it. Cosmetic/data note.
5. **MissilePods** — no slot gate → every caster/hybrid rolls it (already tracked in WA-027).

## Health check
- **No empty pools.** Smallest (4): Sentry, Archon, Liberator, VoidRay. All others ≥5.
- **No dead upgrades** — every active upgrade is rollable by ≥1 unit (D8Charge only via Immortal, per finding 1).
- Inert-but-harmless guards: `Ravager`, `Banshee`, `DefilerMP` NoneOf tags reference units not in any active pool.
