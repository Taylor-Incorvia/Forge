**Wildcard Arena v0.7.3 — 2026-09-13**

**Stalker — no longer starts with Blink**
- Blink is now an upgrade rather than something stalkers have natively. 
- The "enhanced Blink" upgrades (longer-range / shorter-cooldown Blink) are gone — they were trying to cram two upgrades into a one-upgrade system. 

**Raven — minerals 75 → 100 (back to standard)**

**Lurker — range upgrade buffed (+2 → +3)**
- Base range 8 → **11**, Ladder's version is only +2; the Wildcard roll should pop more than ladder since you only get one upgrade.

**Vulture — cleanup**
- Removed the KD8 Charge (reaper grenade) ability. Unit is plenty cost efficient without it. 

**Readability — a big tooltip fix**
- Fixed a large batch of upgrade and ability names that were showing their raw internal id instead of a readable name. Every research now shows a proper name and description when you hover it — on the command card and in the Your Faction panel.
