# Forge SC2 Mod - Project Instructions

## Galaxy Language Rules

When working with `.galaxy` files:

1. **Generated Files**: Files starting with `Lib` (e.g., `LibForge.galaxy`) are auto-generated by the SC2 Editor. Never modify these directly.

2. **Triggers**: Do NOT use `TriggerCreate()` or set up triggers in script. The user creates triggers in the SC2 Editor UI and calls script functions from there. Just write the functions that triggers will call.

3. **Variable Declarations**: Galaxy requires C89-style variable declarations. ALL variable declarations must appear at the TOP of a function, before any other statements.

   ```galaxy
   // CORRECT
   void myFunction() {
       int i;
       string name;
       unit u;

       i = 5;
       name = "hello";
       doSomething();
   }

   // WRONG - will not compile
   void myFunction() {
       doSomething();
       int i = 5;  // ERROR: declaration after statement
   }
   ```

4. **Loop Variables**: Since you can't declare variables mid-function, declare loop variables at the top:

   ```galaxy
   void processUnits() {
       int i;
       int count;

       count = getCount();
       i = 0;
       while (i < count) {
           // ...
           i += 1;
       }
   }
   ```

5. **Cross-file Functions**: Use `include` statements to access functions from other files:
   ```galaxy
   include "TriggerLibs/upgradeHelpers"
   ```

## File Structure

- `TriggerLibs/` - Custom script files
- `GameData/` - XML data files (abilities, units, upgrades, requirements, etc.)
