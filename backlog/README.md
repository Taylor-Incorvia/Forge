# Wildcard Arena — Backlog

This folder is our project board. It replaces Jira with plain markdown that lives next to the code.

## How it works

- **`BOARD.md`** is the index — every ticket, grouped by status. Read this first.
- Each ticket is one file: `WA-###-short-slug.md` with frontmatter (id, status, size, phase, priority).
- Status flow: `backlog` → `todo` (groomed & ready) → `in-progress` → `done`.

## Our two modes

**Mode 1 — Grooming (occasional).** We refine tickets together: I draft/rewrite them, we set priority, we split things that are too big. A ticket is only `todo` once it has a clear *why* and *acceptance criteria* — so future-you never has to re-figure-out what it meant.

**Mode 2 — Doing (most days).** You say *"give me a ticket"* and I hand you one `todo` ticket, scoped and ready, with acceptance criteria. You knock it out. I mark it `done` and update the board.

## Quick commands (just say these)

- **"give me a ticket"** → I pick the top `todo` ticket and brief you.
- **"give me a small one"** → I pick the top `todo` ticket sized `S`.
- **"let's groom"** → we go through `backlog` items and get them ready.
- **"add a ticket: …"** → I write it up and file it.
- **"done"** → I close the active ticket and update the board.

## Sizing

`S` = one sitting (≈30 min). `M` = an afternoon. `L` = multi-session, probably should be split.
